Letakkan foto Anda di folder ini dengan nama: profile.jpg

Foto akan ditampilkan di halaman Pengaturan (developer card).

Rekomendasi:
- Format: JPG atau PNG (tetap pakai nama profile.jpg)
- Resolusi: minimal 400x400, rasio 1:1 (kotak)
- Ukuran: < 500KB

Jika file profile.jpg tidak ada, aplikasi akan menampilkan
icon default (Icons.person) sebagai fallback.
